      Free Chrome extension

      Get warned before you pay a fake toll.

      Tap a link in a "you owe a toll" or "your package is held" text, and Scamouflage shows a full-page warning before you can pay, with the reasons the site looks fake. Every check happens on your own device.

      Download the extension

      Install it in Chrome

      1. Download the extension folder from our project.
      2. Open chrome://extensions and turn on Developer mode.
      3. Click Load unpacked and choose the extension folder.
      4. Pin Scamouflage to your toolbar.

      The extension downloads a signed list every 30 minutes and rejects any list that's tampered with or older than the one it has. Demo mode flags a harmless local test page, so a demo never opens a real scam site.

      Built for the IBM Z Datathon 2026 on one IBM LinuxONE server. We only read public certificate data and never visit suspected scam sites.
